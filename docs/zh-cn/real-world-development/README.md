通过真实场景、完整应用和共享待办列表，了解 GitHub Copilot 在软件开发生命周期中的用法。你将迭代地规划更改、编写代码、测试行为、审查拉取请求，并使用智能体管理工作。

## 场景

你是 Tailspin Toys 的新开发人员。这是一家虚构公司，为以开发为主题的桌游提供众筹服务。团队的待办事项已作为 GitHub issue 创建，你可以立即选择任务。待办事项包括筛选和分页等功能开发，也包括无障碍访问和编码标准等质量改进。

## 选择工作环境

无论你在哪里工作，都可以使用 GitHub Copilot。请选择适合你的开发方式的环境。每个研讨会都有自己的设置步骤，并使用相同的 Tailspin Toys 场景。

### [GitHub Copilot CLI][cli]

在终端中使用智能体助手。使用 Plan 和 Autopilot 模式、说明、技能、自定义智能体、Playwright MCP、Agent Merge 和实用的斜杠命令。

### [GitHub Copilot 应用][app]

并行运行智能体会话、切换会话模式、在画布中协作，并在桌面应用中管理 GitHub issue 和拉取请求。

### [GitHub Copilot 云端智能体][cloud]

将 GitHub issue 分配给异步智能体、指导其工作、监视进度，并审查它创建的拉取请求。

### [Visual Studio Code][vscode]

在 Visual Studio Code 和 GitHub Codespaces 中使用 GitHub Copilot。无需离开编辑器，即可使用 Copilot Chat 智能体模式、MCP 服务器和自定义智能体。
